# 💰 MoneyQuest

Aplicativo web de controle financeiro pessoal com gamificação — transforma
organizar as próprias finanças em uma espécie de jogo, com XP, níveis e
conquistas.

🔗 **Ver ao vivo:** [moneyquest-six.vercel.app](https://moneyquest-six.vercel.app)
(login de demonstração: `demo@moneyquest.com` / senha `dem0`)

## Funcionalidades

**Gestão financeira**
- Registro de transações (entradas e saídas) por categoria, com saldo calculado em tempo real.
- "Cofrinhos" — metas de poupança com prazo.

**Gamificação**
- Ganho de XP ao usar o app (registrar transações, assistir vídeos, cumprir missões).
- 12 níveis, de "Bronze I" a "Lendário".
- Conquistas desbloqueáveis por raridade, missões diárias e ranking global entre usuários.
- Loja de recompensas para trocar XP acumulado.

**Educação financeira**
- Biblioteca de vídeos sobre orçamento, dívidas e renda extra, com filtros por categoria e dificuldade.

**Acessibilidade**
- Temas claro, escuro e de alto contraste.
- Ajuste de fonte, narração por voz (text-to-speech), guia de leitura e comandos de voz em português.

## Como rodar localmente

Não há build nem dependências — é só abrir o `index.html` no navegador.

## Tecnologias

- HTML5, CSS3 e JavaScript
